# Sector capture set, v0.42.0

Six separate early-run gameplay screenshots from the live v0.42.0 game, captured through the existing developer test controls. Each uses its own sector scenery and a different ship. These are actual gameplay frames, not background-only crops or constructed review scenes. Developer runs do not grant unlocks, credits or records. No simulation state was injected through the browser.

| Sector | Ship | Image |
| --- | --- | --- |
| Neon Expanse | Wasp | sector-grid-v0540.webp |
| Shattered Belt | Scavenger | sector-belt-v0540.webp |
| Storm Relay | Tempest | sector-storm-v0540.webp |
| Cinder Foundry | Helios | sector-foundry-v0540.webp |
| Cryo Reach | Glacier | sector-cryo-v0540.webp |
| Neon Undercity | Sovereign | sector-city-v0540.webp |

Each still is cropped directly from gameplay to 960 by 540 pixels. Since v0.54 the menu and website share the same WebP files (`sector-*-v0540.webp`), converted from the original v0.42 JPEG captures. `sector-city-v0420.jpg` is kept for the README and social-preview image. Versioned filenames and the updated offline cache keep returning clients from reusing older scenery previews.
