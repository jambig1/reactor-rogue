# Sector capture set, v0.40.0

Six separate early-run gameplay screenshots from the live v0.40.0 game, captured through the existing developer test controls. Each uses its own sector scenery and a different ship. These are actual gameplay frames, not background-only crops or constructed review scenes. Developer runs do not grant unlocks, credits or records. No simulation state was injected through the browser.
